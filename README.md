# Archie

A portable Telegram bot with local and cloud AI support.

Archie connects to Ollama for local inference or Groq for cloud inference. The setup wizard configures the bot name, tokens, provider, model, and personality. The installer pulls the selected model into a local MODELS folder, and the launcher starts the bot with the saved configuration.

Built for simplicity: one setup script, one install script, one launch script.

WARN = Right now (20/7/26) only apt and pacman package managers supported.
